# "Network from Scratch with Rust"
モダンな言語（Rust?）を用いて，普段World Wide Webで何気なく利用しているサービスを自分の手で構築するチュートリアル．
まずはユーザ側に近い技術から自作に置き換えはじめ，最終的には配信側の技術までRaspberry Pi上で動く軽量なサーバですべて置き換えることを目指す．
僕がCloudflareになる！
